# DXA: снимок → геометрия → контроль качества

Текущий эксперимент на аугментациях завершён: четыре модели, пять эпох, GPU. [Понятный отчёт с примерами](../team_demo/index.html), [публикация в Git](../GIT_PUBLICATION.md). Порог ротации откалиброван по train-оригиналам и автоматически читается из `evaluation/calibration.json`; инструкции ниже также описывают ранние запуски.

Рабочий вход: исходные DICOM из `Исследования/` и завершённые JSON-разметки из `Размеченные/`. Аугментированные данные добавляются через `--augmented-root`. Деление train/validation проводится по `reference_study_uid` через `GroupKFold`; производные test-источников в обучение не входят.

## Модели

1. Маршрутизатор: замороженный ImageNet ResNet18 и обучаемая голова. Он видит исходную ориентацию: правое бедро здесь **не отражается**.
2. Позвоночник: ResNet18 с U-Net декодером для маски межпозвоночных линий и тепловых карт двух подвздошных точек; отдельные головы предсказывают наличие точек. Линии извлекаются из карты вероятностей. Артефакты ищет Faster R-CNN MobileNetV3 FPN как один класс.
3. Бедро: единый ResNet18 с U-Net декодером для обоих боков. Правые бедра отражаются только внутри этой ветви. Выходы: три тепловые карты точек, вероятности их наличия, красная маска малого вертела и три значимые границы ROI; четвёртая граница принудительно доводится до медиального края изображения.
4. Геометрические правила вычисляют флаги по предсказанным объектам. Угол позвоночника считается в миллиметрах, учитывая размеры пикселя по строкам и столбцам. При отсутствии DICOM-тегов используется заданный номинальный масштаб 1,05 мм/Y и 0,6 мм/X.

## Запуск

Из корня проекта в PowerShell:

```powershell
.venv\Scripts\python.exe -m dxa_project.audit_geometry_targets
.venv\Scripts\python.exe -m dxa_project.geometry_ml.train --task all --smoke --size 128 --output dxa_project\outputs\geometry_ml_smoke
.venv\Scripts\python.exe -m dxa_project.geometry_ml.train --task all --epochs 20 --size 256 --batch-size 4 --fold 0 --output dxa_project\outputs\geometry_ml_fold_0
```

Или откройте `dxa_project/DXA_geometry_pipeline.ipynb` с ядром `.venv`. Ноутбук содержит аудит, короткий проверочный запуск, выключенный по умолчанию полный запуск, визуализации и сквозной инференс. Для пяти фолдов изменяйте `FOLD` от 0 до 4. Выходы: `report.json`, четыре `.pt` и PNG-превью. CUDA выбирается автоматически, если доступна.

Когда полный набор аугментаций готов, укажите его папку в ноутбуке через `AUGMENTED_ROOT` или добавьте к команде `--augmented-root путь_к_папке`. Программа связывает каждую аугментацию с исходным исследованием. Синтетические снимки входят только в train; проверка остаётся на исходных DICOM из других исследований.

Короткий запуск проверяет исполнение. Даже 5 эпох не дают готового качества для всех задач. В текущем эксперименте порог площади малого вертела откалиброван по train-оригиналам и равен `0,5 px²`: бинарно это проверка ненулевой маски. Инференс читает порог из `evaluation/calibration.json`; без этого файла используется резервный порог `1 px²`. Метрики считаются по исправленным меткам, а не по прежней «грязной» таблице.
