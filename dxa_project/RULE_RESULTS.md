# Проверка правил из исследовательских ноутбуков

Дата: 26.09.2026. Код: `rule_experiments.py`; результаты: `outputs/rule_experiments/metrics.csv` и `predictions.csv`. Повторный запуск из корня проекта: `python dxa_project/rule_experiments.py`.

Исходные признаки взяты из сохранённых `prototype_output/target_tuning/spine_features.csv`, `hip_features.csv` и `dicom_identity.csv`. Для 99 снимков позвоночника и 149 снимков бедра целевые метки сверены с `разметка.xlsx`; все доступные метки совпали. В сравнение бедра вошли 148 снимков с полным набором проверяемых признаков, принадлежащие 78 исследованиям. Для каждого нового правила порог подбирался **только на обучающей части каждого фолда**, затем прогноз записывался на отложенные исследования. Использовался `StratifiedGroupKFold` по папке исследования, до пяти фолдов. Критерий подбора — среднее balanced accuracy и F2. Правила прежнего ноутбука использовали параметры, ранее подобранные на всех данных; их строка в таблице является справкой, а не независимой оценкой. После просмотра нескольких гипотез эта сравнительная таблица также остаётся исследовательской оценкой, не финальным тестом.

| Цель | Правило | TP / FN | FP / TN | Чувствительность | Специфичность | Balanced accuracy |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Укладка позвоночника | старое сложное правило | 6 / 0 | 56 / 37 | 1,00 | 0,40 | 0,70 |
| Укладка позвоночника | малый медианный зазор между позвонками | 4 / 2 | 24 / 69 | 0,67 | 0,74 | 0,70 |
| Ось позвоночника | фиксированные **5°** по границе кости | 7 / 3 | 22 / 67 | 0,70 | 0,75 | 0,73 |
| Ось позвоночника | подбираемый порог по той же границе | 7 / 3 | 29 / 60 | 0,70 | 0,67 | 0,69 |
| Артефакты | старое сложное правило | 12 / 5 | 30 / 52 | 0,71 | 0,63 | 0,67 |
| Артефакты | яркие пиксели у края | 11 / 6 | 36 / 46 | 0,65 | 0,56 | 0,60 |
| Позиционирование/ротация бедра | старое сложное правило | 27 / 8 | 82 / 31 | 0,77 | 0,27 | 0,52 |
| Позиционирование/ротация бедра | нормированное смещение сечения вертела | 27 / 8 | 56 / 57 | 0,77 | 0,50 | 0,64 |
| ROI бедра | старое правило трёх относительных отступов | 0 / 6 | 22 / 120 | 0,00 | 0,85 | 0,42 |
| ROI бедра | малый нижний **или** боковой отступ | 4 / 2 | 20 / 122 | 0,67 | 0,86 | 0,76 |
| ROI бедра | только малый нижний отступ | 3 / 3 | 10 / 132 | 0,50 | 0,93 | 0,71 |

Полное обучение порогов на этих данных даёт ориентиры для следующего эксперимента: нижний отступ ROI `< 0,343` высоты изображения, боковой `< 0,170` ширины; нормированное смещение сечения вертела `> −0,047` меньшего размера кадра; медианный зазор между позвонками `< 42` пикселей. Фолдовые пороги сохранены в CSV. Эти значения **не являются клиническими порогами**. Для измерения 3 и 2 см нет подтверждённого физического масштаба DICOM. Вариант зазора, нормированный на высоту снимка, оказался хуже, поэтому пиксельный порог нельзя переносить на новое разрешение как готовое правило.

Вывод по гипотезам: фиксированный порог 5° из постановки выглядит лучше подбираемого на этих данных. Для ротации бедра прежнее составное условие давало много ложных тревог; смещение сечения малого вертела после нормировки снизило их число при том же числе найденных нарушений. Для ROI сочетание нижнего и бокового отступов обнаружило четыре из шести нарушений; при требовании меньшего числа ложных тревог можно проверять только нижний отступ. Новые одиночные признаки артефактов не улучшили прежний набор. Эти правила остаются кандидатами для визуального разбора ошибок и проверки на новых исследованиях; шесть положительных ROI слишком мало для надёжной фиксации порога.

Для чувствительности ROI 4/6 точный 95% биномиальный интервал составляет примерно 0,22–0,96. Он показывает, насколько неопределён результат даже до учёта перебора гипотез.
