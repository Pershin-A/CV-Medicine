# DXA labeler v4.4-fast-side-metal

Правильная версия легко узнаётся:
- заголовок содержит `4.4-fast-side-metal`;
- в sidebar показана версия;
- после `Класс` видны `Сторона ноги` и `Металл / имплант`.

Ускорение:
- `/data` сканируется один раз и кэшируется;
- preview текущего DICOM кэшируется;
- metadata не читается, пока не включён checkbox;
- изображение читается из `/data`, а `labels.csv` является главным реестром;
- известные warnings исходных DICOM по VR UI/LO скрыты из Docker logs.
