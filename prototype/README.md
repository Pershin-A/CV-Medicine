# DXA Analysis Prototype

Jupyter Notebook с экспериментальными алгоритмами анализа DXA/DICOM-изображений.

Основной notebook:

```text
DXA_prototype_v5_3.ipynb
```

## Назначение

Prototype исследует шесть основных задач контроля качества DXA.

### Проксимальный отдел бедра

1. **Позиционирование**

   Анализируются три характерные структуры. Для каждой области ищется минимальная ненулевая ширина вдоль линий с заданной ориентацией.

2. **Ротация**

   Анализируется контур кости в области характерного «горбика». Используется локальный градиент и изменение направления контура.

3. **Металл**

   Используются скрытые представления pretrained ResNet. Изображения с металлом сравниваются с распределением представлений изображений без металла.

### Позвоночник

4. **Угол позвоночника**

   Строится геометрическая ось позвоночника и вычисляется её угол относительно вертикали.

5. **Позиционирование**

   Используется pretrained segmentation model для выделения подвздошных областей. Рассчитывается их суммарная площадь как доля площади изображения.

6. **Деформация / сколиоз**

   По ярким структурам строятся локальные оси позвонков. Разность ориентаций верхнего и нижнего сегментов используется как экспериментальный геометрический показатель.

## Определение корня проекта

Не рекомендуется использовать абсолютный путь вида:

```python
Path(r"C:\Users\...\project")
```

Вместо этого используется поиск корня проекта:

```python
def find_project_root(start=Path.cwd()):
    start = start.resolve()

    for path in [start, *start.parents]:
        if (path / "labeler").is_dir() and (path / "prototype").is_dir():
            return path

    raise FileNotFoundError("Не удалось определить корень проекта.")


DATASET_ROOT = find_project_root()
```

Это позволяет запускать notebook на разных компьютерах без изменения пользовательского пути.

## Размеры изображений

Диагностические визуализации намеренно строятся компактными, чтобы можно было одновременно анализировать изображение и рассчитанные признаки.

## Обучение классификаторов

В текущем prototype часть классификаторов обучается и оценивается на одном и том же наборе размеченных изображений.

Поэтому такие метрики являются **in-sample metrics** и не являются оценкой качества модели на новых пациентах.

Для полноценной оценки необходимо использовать независимое разбиение на train/validation/test с разделением на уровне пациента или исследования.

## Ограничения

Проект является исследовательским prototype.

Используемая сегментационная модель не обучалась специально на данном DXA-наборе.

Автоматически выделенные подвздошные области необходимо визуально контролировать.

Геометрический показатель деформации позвоночника:

```text
|angle_first_segment - angle_last_segment|
```

является экспериментальным признаком.

Он не является клиническим углом Cobb и не должен интерпретироваться как медицинский диагноз.
