# DXA prototype v3 — изменения

1. Позвоночник: локальные минимумы ранжируются по prominence; между выбранными границами минимум H/8; максимум 6 границ.
2. Горбик: полностью убрана threshold/binary-mask логика; используется трассировка сильной границы на нормализованном изображении.
3. Бедро: bounding box для 3 точек больше не используется; точки выбираются вручную кликами. Для каждой точки сканируются параллельные линии заданного угла, ширина = число ненулевых пикселей.
4. Классификаторы LEG/SPINE и NO_METAL/METAL: train и evaluation выполняются на всех доступных размеченных данных.
5. labels.csv: добавлен устойчивый resolver relative_path -> локальный DICOM с exact/suffix/basename fallback и диагностикой unresolved paths.
