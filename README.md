# Порядок действий

## 1. Установите Docker Desktop

Для Windows достаточно установить Docker Desktop.

После установки запустите Docker Desktop и дождитесь, пока Docker Engine станет активным.

Для проверки откройте PowerShell и выполните:

```powershell
docker --version
docker compose version
```

В ответ должны появиться версии Docker и Docker Compose.

---

## 2. Создайте рабочую папку

Например:

```text
C:\DXA_labeling
```

---

## 3. Поместите туда DICOM-данные

Папка с исследованиями должна находиться по пути:

```text
C:\DXA_labeling\Исследования
```

Внутренняя структура папки `Исследования` может быть вложенной. Приложение рекурсивно найдёт все файлы с расширением `.dcm`.

Пример:

```text
C:\DXA_labeling\
└── Исследования\
    ├── 2.25....
    │   └── series_003_2_CR\
    │       └── A250496619 DXA\
    │           └── CR DXA\
    │               ├── CR000000.dcm
    │               ├── CR000001.dcm
    │               └── ...
    └── ...
```

---

## 4. Распакуйте приложение

Распакуйте архив `dxa_labeler.zip` в папку:

```text
C:\DXA_labeling\dxa_labeler
```

В итоге структура должна выглядеть так:

```text
C:\DXA_labeling\
├── Исследования\
│   └── ...
│
└── dxa_labeler\
    ├── app.py
    ├── Dockerfile
    ├── docker-compose.yml
    ├── requirements.txt
    └── README.md
```

Папка `Размеченные` заранее не обязательна. Она будет создана автоматически.

---

## 5. Откройте PowerShell

Перейдите в папку приложения:

```powershell
cd "C:\DXA_labeling\dxa_labeler"
```

---

## 6. Первый запуск

Выполните:

```powershell
docker compose up --build
```

При первом запуске Docker:

* скачает базовый Python-образ;
* установит необходимые Python-библиотеки;
* соберёт контейнер;
* запустит Streamlit-приложение.

После успешного запуска откройте в браузере:

```text
http://localhost:8501
```

---

# Работа с приложением

## 7. Выбор DICOM-файла

Приложение автоматически найдёт все `.dcm` файлы внутри:

```text
C:\DXA_labeling\Исследования
```

Файлы можно открывать двумя способами:

* последовательно кнопками:

  * `← Пред.`
  * `След. →`
* выборочно через выпадающий список файлов.

---

## 8. Просмотр изображения

Для выбранного DICOM-файла приложение показывает изображение DXA.

При отображении учитываются стандартные DICOM-параметры, включая:

* `RescaleSlope`;
* `RescaleIntercept`;
* VOI LUT;
* Window Center / Window Width;
* `MONOCHROME1`.

---

## 9. Ручная разметка

Для каждого DICOM-файла необходимо выбрать один из классов:

```text
Позвоночник
Нога
Не определено
```

В DICOM они сохраняются как:

```text
SPINE
LEG
UNKNOWN
```

Также можно указать:

* имя разметчика;
* дополнительный комментарий.

---

## 10. Сохранение разметки

Есть две кнопки:

```text
Сохранить
```

и

```text
Сохранить и следующий →
```

Рекомендуемый вариант при последовательной разметке:

```text
Сохранить и следующий →
```

После сохранения приложение автоматически перейдёт к следующему DICOM-файлу.

---

# Где сохраняются результаты

Исходные DICOM-файлы не изменяются.

Папка:

```text
C:\DXA_labeling\Исследования
```

подключается к Docker-контейнеру в режиме только для чтения.

Размеченные копии сохраняются в:

```text
C:\DXA_labeling\Размеченные
```

Например:

```text
Исследования\
└── 2.25.9198...\
    └── series_003_2_CR\
        └── A250496619 DXA\
            └── CR DXA\
                └── CR000000.dcm
```

будет сохранён как:

```text
Размеченные\
└── 2.25.9198...\
    └── series_003_2_CR\
        └── A250496619 DXA\
            └── CR DXA\
                └── CR000000.dcm
```

Таким образом, исходная структура папок полностью сохраняется.

---

# Что добавляется в DICOM

Для ручной разметки используется отдельный private DICOM block.

Private Creator:

```text
DXA_MANUAL_LABELER
```

В него записываются:

```text
ManualLabel
Notes
Annotator
AnnotatedDateTime
```

Пример:

```text
ManualLabel: SPINE
Notes:
Annotator: Ivan
AnnotatedDateTime: 20260916221531
```

Исходные медицинские поля DICOM не перезаписываются.

---

# Файл labels.csv

Кроме размеченных DICOM-файлов автоматически создаётся:

```text
C:\DXA_labeling\Размеченные\labels.csv
```

Пример содержимого:

```csv
relative_path,label,notes,annotator,annotated_at
2.25.../CR000000.dcm,SPINE,,Ivan,2026-09-16T22:15:31
2.25.../CR000001.dcm,LEG,,Ivan,2026-09-16T22:16:02
```

Этот файл удобно использовать в дальнейшем для подготовки датасета для машинного обучения.

---

# Просмотр DICOM-метаданных

Под изображением находится таблица со всеми DICOM-метаданными.

Для каждого поля отображаются:

```text
Section
Tag
Keyword
Name
VR
Value
```

Также доступен поиск по метаданным.

Например, можно искать:

```text
Patient Orientation
```

или:

```text
0020
```

или:

```text
Image Comments
```

---

# Повторное открытие уже размеченного файла

Если DICOM уже был размечен, приложение использует ранее сохранённую копию из папки:

```text
Размеченные
```

В интерфейсе будет показано сообщение о том, что для файла уже существует размеченная версия.

При этом автоматически загружаются ранее сохранённые:

* класс;
* комментарий;
* имя разметчика.

Разметку можно изменить и сохранить повторно.

---

# Последующие запуски

После первого запуска пересобирать Docker-образ обычно не требуется.

Откройте PowerShell:

```powershell
cd "C:\DXA_labeling\dxa_labeler"
```

Запустите приложение:

```powershell
docker compose up -d
```

После этого откройте:

```text
http://localhost:8501
```

---

# Остановка приложения

Выполните:

```powershell
cd "C:\DXA_labeling\dxa_labeler"
docker compose down
```

---

# Что отправить после завершения разметки

После окончания работы необходимо передать папку:

```text
C:\DXA_labeling\Размеченные
```

В ней находятся:

```text
Размеченные\
├── labels.csv
│
└── размеченные DICOM-файлы
```

Особенно важен файл:

```text
labels.csv
```

Он содержит итоговую таблицу ручной разметки.

---

# Краткая инструкция

```text
1. Установите и запустите Docker Desktop.

2. Создайте папку:
   C:\DXA_labeling

3. Поместите DICOM-данные в:
   C:\DXA_labeling\Исследования

4. Распакуйте dxa_labeler.zip в:
   C:\DXA_labeling\dxa_labeler

5. Откройте PowerShell:

   cd "C:\DXA_labeling\dxa_labeler"

6. При первом запуске выполните:

   docker compose up --build

7. Откройте браузер:

   http://localhost:8501

8. Для каждого изображения выберите:

   - Позвоночник
   - Нога
   - Не определено

9. Нажимайте:

   "Сохранить и следующий →"

10. После окончания работы остановите приложение:

    docker compose down

11. Передайте папку:

    C:\DXA_labeling\Размеченные
```
