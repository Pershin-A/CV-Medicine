# DXA Quality Control Prototype

Прототип системы для анализа DXA/DICOM-изображений и контроля качества исследований проксимального отдела бедра и позвоночника.

Проект состоит из двух основных частей:

- `labeler` — Streamlit-приложение для ручной разметки DICOM;
- `prototype` — Jupyter Notebook с алгоритмами обработки изображений и ML/CV-прототипами.

Исходные медицинские данные и разметка не входят в Git-репозиторий.

## Данные

### `Исследования`

Каталог с исходными DICOM-файлами.

Текущий набор, использовавшийся при разработке, содержит 499 DICOM.

Исходные DICOM используются только для чтения и не модифицируются.

### `Размеченные`

Каталог с копиями размеченных DICOM и основным реестром:

```text
Размеченные/labels.csv
```

Основные поля разметки:

| Поле | Назначение |
|---|---|
| `label` | `LEG` / `SPINE` |
| `side` | `LEFT` / `RIGHT` для бедра |
| `metal` | наличие металла / импланта |
| `fracture` | наличие перелома |
| `spine_issue` | патология позвоночника |
| `notes` | комментарий разметчика |
| `annotator` | разметчик |
| `annotated_at` | время разметки |

### `разметка.xlsx`

Дополнительная клиническая/экспертная таблица.

Приложение разметки сопоставляет строки таблицы с текущим `study` и показывает:

- положительные признаки со значением `1`;
- итог для текущей области;
- комментарий.

Нулевые значения и пропуски в интерфейсе не выводятся.

## Приложение для разметки

Перейти в:

```powershell
cd labeler
```

Создать локальный `.env`:

```powershell
Copy-Item .env.example .env
```

Запустить:

```powershell
docker compose up -d --build
```

Интерфейс:

```text
http://localhost:8501
```

Подробнее: [`labeler/README.md`](labeler/README.md).

## Prototype

Установить зависимости:

```powershell
pip install -r prototype/requirements.txt
```

Открыть:

```text
prototype/DXA_prototype_v5_3.ipynb
```

Prototype содержит обработку DXA-изображений, извлечение геометрических признаков и демонстрационные ML/CV-алгоритмы.

Подробнее: [`prototype/README.md`](prototype/README.md).

## Основные задачи prototype

Для изображений бедра:

1. оценка позиционирования по характерным узким участкам;
2. оценка ротации по геометрии контура;
3. обнаружение металла по скрытым представлениям CNN.

Для позвоночника:

1. оценка угла оси позвоночника относительно вертикали;
2. оценка положения по сегментации подвздошных костей;
3. оценка деформации позвоночника по локальным осям позвонков.

## Важно

Проект является исследовательским прототипом.

Получаемые геометрические и ML-признаки не являются медицинским диагнозом и не должны использоваться как самостоятельное основание для клинических решений.

В частности, вычисляемый показатель деформации позвоночника является экспериментальным признаком и не эквивалентен клиническому углу Cobb.
